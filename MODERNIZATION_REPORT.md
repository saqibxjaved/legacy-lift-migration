## Dependency Smells

1. God Class — admin.java: Combines Swing UI, JDBC, SQL, and user-status mutation in a single 316-LOC JFrame. Cyclomatic complexity 21.
2. Hardcoded Credentials — admin.java: JDBC URL with root/Sudhir@123 on 4 call sites.
3. Tight Coupling Presentation→Database — admin.java: JFrame event handlers directly open JDBC connections with no service/repository layer.
4. Feature Envy — admin.java: GUI methods duplicate User domain logic (search, approval) that belongs to UserService/UserRepository.
5. ADR-001 Latent Risk: architectural pressure for OrderProcessor to validate user state must be actively suppressed.
6. Dead Artifact — customer.java: 515-LOC NetBeans XML form with zero Java logic.

## Detailed Findings

### [P0-CRITICAL] Hardcoded Database Credentials in Source Code
File: admin.java:41, 192, 235, 255
Description: MySQL credentials (root/Sudhir@123) hardcoded in DriverManager.getConnection() across 4 methods.
Evidence: DriverManager.getConnection("jdbc:mysql://localhost:3306/hotel","root","Sudhir@123")
Recommendation: Remove credentials, rotate password, load from environment variables or secrets manager. Add pre-commit secret scanning.

### [P0-CRITICAL] Log4Shell — Remote Code Execution via JNDI Lookup
File: pom.xml → log4j-core 2.14.1
CVE: CVE-2021-44228 (CVSS 10.0)
Description: log4j-core 2.14.1 is vulnerable to unauthenticated RCE via JNDI lookup in log messages.
Recommendation: Upgrade to 2.17.2+. RESOLVED BY MIGRATION: Python uses stdlib logging — no Log4j equivalent.

### [P1-HIGH] Unsafe Java Deserialization via Apache Commons Collections
File: pom.xml → commons-collections 3.2.1
CVE: CVE-2015-6420, CVE-2015-7501 (CVSS 9.8)
Recommendation: Upgrade to 3.2.2+. RESOLVED BY MIGRATION: not applicable in Python.

### [P1-HIGH] No Authentication or Authorization on Admin Operations
File: admin.java (all methods)
Description: Zero authentication gates on any admin DB operation. No audit logging.
Recommendation: Add login dialog, bcrypt password hashing, RBAC, audit log. In Python: JWT auth on all endpoints.

### [P1-HIGH] Silent Exception Swallowing Masks Security Events
File: admin.java (multiple catch blocks)
Description: Empty catch blocks suppress all errors including security-relevant ones.
Recommendation: Restore structured logging; in Python never use bare except: pass.

## Migration-Introduced Risks

2. Pickle deserialization — use JSON/msgpack instead for any caching layer

4. FastAPI insecure defaults — disable debug mode, harden CORS, set SECRET_KEY
5. Over-logging PII — use structured logging with explicit field allowlists
6. Dependency pinning drift — add pip-audit/Safety CLI to CI
7. Status typo "panding" propagation — normalize at migration boundary
