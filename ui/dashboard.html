How to Use LegacyLift
Step-by-step setup and run guide
What is LegacyLift? — An automated pipeline that uses IBM Bob 2.0 to orchestrate 3 specialist AI agents, a 16-tool MCP server, and a validation loop to migrate Java monoliths to Python or TypeScript — fully automatically, in under a minute.
Prerequisites
RequirementVersionPurpose
IBM Bob 2.0LatestOrchestrator + agent runner
Node.js18+MCP server runtime
Python3.9+Migrated code + test runner
npm8+MCP server build tool
Setup & Run
1
Build the MCP Server
The MCP server provides 16 engineering tools Bob uses during migration. Build it once.
cd mcp-server npm install npm run build
2
Register MCP Server in Bob
Open your workspace .bob/mcp.json and add the LegacyLift server entry so Bob can call its tools.
{ "mcpServers": { "legacylift-mcp": { "command": "node", "args": ["mcp-server/build/index.js"] } } }
3
Install Python Dependencies
Install pytest and pylint so the Testing Agent can run and validate migrated code.
pip install -r requirements.txt
4
Switch to Migration Orchestrator Mode
In Bob, open the mode picker (bottom-left of the chat window) and select Migration Orchestrator. This mode is defined in .bob/custom_modes.yaml and gives Bob the right instructions and permissions for the pipeline.
5
Point to Your Java Source
Edit workflow/pipeline-config.json to point to your Java files and choose the output language.
{ "source": { "root_dir": "demo/java-source" }, "target": { "language": "python", "output_dir": "demo/migrated-output" }, "validation": { "min_test_pass_rate": 0.8 } }
6
Run the Pipeline
In Bob's chat (with Migration Orchestrator mode active), type the command below. Bob will automatically run all 6 stages and produce a full report.
Run the migration pipeline using workflow/pipeline-config.json
7
Review the Modernization Report
When the pipeline completes, Bob writes demo/migrated-output/MODERNIZATION_REPORT.md. It contains: migrated files, test results, security findings, behavior diff, and code metrics. Open this dashboard to browse results visually.
